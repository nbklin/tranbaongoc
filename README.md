# ASTRALIS — Trần Bảo Ngọc

A personal command center for university work, projects, goals, tasks, research, notes, and achievements.

## Run locally

Open `index.html` in a modern browser. ASTRALIS is a static web app. Data is saved in that browser's local storage and remains on the device.

## Publish with GitHub Pages

Create a repository named `tranbaongoc`, upload the files in this folder to the repository root, then enable Pages from the `main` branch and `/ (root)` in the repository's Pages settings.

The expected project site URL under the existing `nbklin` account is `https://nbklin.github.io/tranbaongoc/`.
